## 2. Origine et description

| Champ | Valeur |
|---|---|
| Origine de la demande | Point ouvert signalé après D-024 : la matrice v0.3 n'accorde à aucun agent le droit de committer `audit_report/**`, laissant les livrables AUDITOR hors dépôt |
| Description du changement | Autoriser l'ORCHESTRATOR à committer et pousser `audit_report/**` sur `dev_sprint_XX` **à titre de dépositaire**, sans modifier le contenu des fichiers produits par l'AUDITOR |
| Élément affecté | Règle de gouvernance validée (matrice de permissions) |
| Justification | L'AUDITOR doit rester indépendant et ne pas committer (§2.3) ; l'ORCHESTRATOR est le seul agent habilité à versionner les livrables de gouvernance |
| Niveau de risque qualitatif | faible |
| Justification du niveau | Droit purement technique de dépôt ; aucun contenu n'est modifié, aucun rôle de vérification n'est transféré |

## 4. Options examinées

| Option | Description | Avantages | Inconvénients | Réversibilité |
|---|---|---|---|---|
| A (retenue) | ORCHESTRATOR dépositaire de `audit_report/**`, sans modification de contenu | Préserve l'indépendance AUDITOR ; versionne les preuves ; cohérent avec le rôle de gestionnaire de l'ORCHESTRATOR | Exige une vérification d'empreinte avant chaque commit | R1 |

| C (écartée) | Donner le droit de commit à l'AUDITOR | Dépôt direct par le producteur | Brise l'indépendance procédurale (GC-37) et la règle §2.3 | R1 |
