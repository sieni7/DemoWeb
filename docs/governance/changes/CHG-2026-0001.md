## 2. Origine et description

| Description du changement | Amendement de `AGENTS.md` §3 : distinguer les droits de `git commit` / `git push` selon la nature des fichiers (gouvernance vs code) ; ajouter `reference/**` aux fichiers possédés par l'ORCHESTRATOR ; ajouter `sprint_report/**` aux livrables BUILDER |
| Élément affecté | Règle de gouvernance validée (matrice de permissions) |

| Niveau de risque qualitatif | modéré |
| Justification du niveau | Change une règle déclarée, sans modifier le code ni les critères d'acceptation ; laisse la protection technique `unknown` (GC-36) |
